# Images and public/private boundary

Search exact landmark+city+coordinates. Verify identity; prioritize traceable permission (e.g. Commons). Record source, author, license and verifiedRealPlace in ledger/credits. Search thumbnails are not rights evidence. User replacements win. Failed search: inform at confirmation, accept supplied image; otherwise labeled contextual art/no-image card. Never show generated scenery as real photography.

Infer daily themes (departure/transit/seaside/walking/museum/food/rest/return). Explicit mappings win; otherwise match pool and show reason. No usable pool: ask AI generation or remove. AI style consistent, variation follows actual daily plan. If generation unavailable, explain and use legitimate generic art/user media or omit. Omission removes layout spacing. Private memes are not public defaults without redistribution rights.

Private inputs/outputs live outside this repository: real tickets/QRs/names/booking references/photos/signing keys/passwords/APKs. APKs can be extracted; confirm private use before ticket embedding. Never publicly host tickets by default. PWA local-device import preferred; authenticated private hosting is an advanced explicit choice. Backups contain private notes/images; tell user to store privately.

Release gate: allowlist files, inspect binaries and archives, search for personal/booking/credential strings, confirm all demo content fictional and media rights documented. `.gitignore` alone is insufficient. Do not wholesale copy existing app assets/build/browser profiles. MIT covers original code/templates only; retain third-party licenses.

Input rendering uses textContent, no user HTML interpolation. Reject traversal/absolute paths/unexpected schemes. Scope IndexedDB/localStorage/service-worker caches by tripId, never delete another app's cache. Cache declared app/trip assets only; binary errors never replaced with HTML. Corrupt/encrypted/unsupported tickets show recoverable errors.
